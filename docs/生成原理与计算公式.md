# 生成原理与计算公式（v0.3）

核对日期：2026-10-29  
适用范围：当前 `生成器/直角戗角/` 源码与默认参数。本文解释几何定义、公式和离散近似；完整的程序阶段与调用顺序见[程序执行过程](程序执行过程.md)。

希望先从营造做法理解这些公式，可阅读[从书中做法到生成公式](从书中做法到生成公式.md)，其中按放样顺序解释书图依据、几何理解和项目补充假设。

本版按输入角度重建骨架和关联构件，两翼关于建筑角平分面刚体镜像；尺寸使用毫米，不将旧网格整体拉伸。飞椽先由共同虚拟母板定义，再按每根椽的带域截取；里口承口从同一带域和母板底面求切。上层卷戗板按全翼连续曲面生成。排料只取一侧立脚飞椽的中心截面作为梯形近似。

## 1. 坐标、符号与输入单位

模型坐标为右手世界坐标：平面位置用 `X/Y`（mm），高度用 `Z`（mm，竖直向上）。第一翼檐桁沿世界 `X` 轴，出檐方向为 `+Y`。第二翼通过平面内角的角平分面反射得到，非直角时它一般不与 `Y` 轴重合。

| 符号 / 字段 | 含义 | 单位或约束 |
| --- | --- | --- |
| `α` / `corner_angle_deg` | 从建筑转角向屋内的两条檐桁轴线射线之间的平面内角 | 度；有限且 `0 < α < 180` |
| `h=α/2` | 建筑角半角 | 计算用弧度；输入和展示为度 |
| `D` | 界深，沿第一翼檐桁的法向量取 | mm |
| `e` | 正身檐出水平长度 | mm |
| `p` | 正身飞椽水平外挑，不含后尾 | mm |
| `t` | 提栈系数；两道桁轴的高度差为 `D·t` | 无量纲 |
| `B` | 摔网分档使用的中心档控制上限 | mm；不是成品椽间净距 |
| `k_c`、`c=k_c p` | 放叉系数及放叉量 | 系数无量纲，`c` 为 mm |
| `L_n`、`U_n` | 嫩戗空间控制弦长、相对升高 | mm；要求 `0<U_n<L_n` |
| `a`、`w_fly` | 老戗截面尺度、飞椽宽度 | mm；`w_fly` 也用于排料板厚 |
| `q`、`v` | 飞椽局部纵向站位、横向站位 | mm；`v=0` 是中心线 |
| `I/S/E/R` | 飞椽里口前缘点、里口外缘交点、梢端、后尾根点 | 点名；其沿椽站位通常满足 `q_R<q_I<q_S<q_E` |

配置必须明确含有 `corner_angle_deg`。90° 是默认配置和界面预置值；旧 JSON 省略此字段会被拒绝，不会静默补成90°。[参数校验与派生](../engine/config.py#L85)

主要默认值可从 [默认配置](../configs/default.json) 和[参数说明](../参数说明.md)核对。下文只展开会影响几何关系的字段；所有木料尺寸保持原毫米量值，角度变化不会按比例改写木料宽厚。

## 2. 非直角平面骨架

### 2.1 半角方向和镜像

令 `h=α/2`。基准老戗的平面单位方向与法向为：

```text
u = (cos h, sin h)
v = (-sin h, cos h)
```

角平分面沿 `u`，其单位法向是 `v`。点 `P=(x,y)` 关于过原点的角平分面反射为：

```text
P' = P - 2 (P·v) v
```

三维反射对 `Z` 保持不变。程序对同一侧建立基准几何，再用该刚体反射得到另一侧；不会把第二翼固定设成世界 `Y` 轴，也不会对旧构件网格做整幅拉伸。[半角、镜面和反射函数](../engine/stage02_core.py#L50)

### 2.2 老戗控制线、嫩戗投影和派生夹角

基准老戗平面控制线端点在当前坐标约定下为：

```text
P_old,start = (-D cot h, -D)
P_old,end   = ((e+c) cot h, e+c)
c           = k_c p
```

老戗方向沿 `u`，截面横向沿 `v`。步桁轴高由 `z_step=D·t` 派生，廊桁轴高为当前基准 `z_eave=0`。[骨架派生](../engine/stage02_core.py#L124)

嫩戗控制弦长按空间直线长度解释。它在平面中的投影长度为：

```text
L_plan = sqrt(L_n² - U_n²)
θ_young = asin(U_n / L_n)
```

嫩戗根中心沿老戗方向从老戗梢退进 `setback`：`P_root = P_old,end - setback·u`。中心线以 `L_plan` 沿 `u` 前进，`Z` 方向上升 `U_n`。所以输入的是空间弦和竖向升高，不是将老网格的平面坐标统一缩放。[嫩戗中心线及控制弦](../engine/stage03_core.py#L55)

当前报告的老、嫩戗控制线夹角由两条实际控制方向派生：

```text
θ_old = atan(t sin h)
θ_young = asin(U_n / L_n)
θ_included = 180° - θ_young - θ_old
```

`θ_included` 不是 `corner_angle_deg`，也不是用户可独立输入的第二个建筑角。[配置派生关系](../engine/config.py#L154)

以 [默认配置](../configs/default.json) 为例：`α=90°`、`h=45°`、`D=1200`、`e=600`、`p=300`、`t=0.5`、`k_c=0.9`、`L_n=900`、`U_n=480`。于是 `z_step=600 mm`、`c=270 mm`、老戗端点为 `(-1200,-1200)` 与 `(870,870) mm`，嫩戗平面投影约 `761.315 mm`，`θ_young≈32.23°`、`θ_old≈19.47°`，派生控制线夹角约 `128.30°`。这只是参数公式示例，不是实体加工或承载验收。

## 3. 控制弧、弧向分椽与高度场

### 3.1 以内切线确定的平面圆弧

摔网弧从檐端点 `A` 出发，在 `A` 处与正身檐端线相切，切线沿水平 `+X`；弧向步桁一侧内凹。设 `B` 是老戗近侧边上的控制点，`dx=B_x-A_x`、`dy=B_y-A_y`，实现要求两者均为正。圆心、半径为：

```text
C_arc = (A_x, A_y + R)
R = (dx² + dy²) / (2 dy)
```

弦长、圆弧角、弧长和弦矢高为：

```text
L_chord = sqrt(dx² + dy²)
Θ = θ_1 - (-π/2)
L_arc = R Θ
s_arc = R - sqrt(R² - L_chord²/4)
```

弧矢高由端点和切线产生。参数 `likou_width` 的55 mm只作为比较参考，不会强迫圆弧达到55 mm。[圆弧构造与派生值](../engine/stage02_core.py#L378)

程序把这条弧采为129个等参数站点，用折线段参与交点查找、表面和实体放样；弧本身的解析关系与生产中的折线/放样不是同一层精度。[扇区设置及采样数](../engine/stage02_core.py#L446)

### 3.2 弧向等分和根数

以 `L_arc` 为弧长，选满足 `L_arc/n < B` 的最小奇数区间数 `n`，从3开始按2递增。内部等分点 `i/n`（`i=1…n−1`）确定 `n−1` 根真摔网椽中心射线：

```text
P_i = Arc(i/n)
ray_i(q) = O + q (P_i-O) / |P_i-O|
```

两个弧端点是边界，不另算真摔网椽。檐端与 `x=-D` 同轴的出檐椽保留在普通正身边界组，只计一次。`B` 控制的是弧长分档密度，不是飞椽成品净距，也不能由最终根数反推。[奇数区间分档](../engine/stage02_core.py#L420)；[中心射线及边界分类](../engine/stage02_core.py#L636)

### 3.3 摔网顶高程的离散控制场

令 `s` 是从角点 `O` 观察位置 `(x,y)` 后，在129点弧折线上定位得到的弧向参数；令 `P(s)` 为相应弧点。径向参数为：

```text
r = clamp(((X-O)·(P(s)-O)) / |P(s)-O|², 0, 1)
```

基准正身侧和老戗侧的控制高程先分别沿 `r` 插值，再沿 `s` 插值：

```text
z_straight(r) = z_O + (z_A-z_O) r
z_old(r)      = old_side_top(r)
z_top(X)      = (1-s) z_straight(r) + s z_old(r)
```

`old_side_top(r)` 取老戗实际截面主体上缘；根部闭合修整量从 `O` 向 `B` 线性衰减。故顶高程是采样弧参数化和分段插值组成的控制场，不是任意两条弯曲曲面求交后的精确解析面。[摔网高度插值](../engine/stage02_core.py#L430)

单根摔网椽以 `O` 到弧上中心分点的射线放置。它沿椽长取若干离散截面，横向轴为射线的水平法向；两侧顶点分别读取 `z_top`，底面按椽高向下平移。因此宽度方向允许顶面变化，纵向截面之间以直纹放样连接。[摔网椽截面](../engine/stage02_core.py#L601)

### 3.4 嫩戗车背小弧

嫩戗主体中心线与控制弦保持直线。当前浅弧只作用于截面上凸起的车背，矢高取根梢车背高度的较小值的0.75倍。圆弦长为 `L_n`、矢高为 `s` 时：

```text
R_carback = L_n²/(8s) + s/2
```

`arc_young_profile()` 用33个弦向样点按圆方程求下挠量，再随截面收分构成车背。历史的112.5 mm组合上轮廓参考没有压到嫩戗主体、底线或中心线中。[车背圆弧和嫩戗截面](../engine/stage03_core.py#L37)

## 4. 下层板面和飞椽定位

### 4.1 下层望板的控制面

正身摔网根点 `O` 与檐端 `A` 给出整翼正身板的共同平面控制线。对纵向站位 `q`，程序按两点线性插值高程：

```text
z_board(q) = z_O + (z_A-z_O) (q-q_O)/(q_A-q_O)
```

正身板沿分档边界分片，板厚为 `board_lower_t`，下表面相对控制面有0.2 mm建模搭接。摔网板的内边界由控制弧向 `O` 偏置 `likou_width`，再沿 `O` 到偏置弧形成的扇区放样；通常每翼一个扇区面，若整体放样失败则按相邻扇区分成三角放样片。板面取样吻合度仅在固定网格上报告，不能视为全域误差上界。[正身板平面](../engine/stage03_core.py#L218)；[摔网板扇区](../engine/stage03_core.py#L285)

### 4.2 梢端曲线与射线交点

立脚飞椽的外端曲线另由 `A=(x_old,start, e+p)` 和嫩戗梢部侧顶点 `B` 决定。它同样在 `A` 处取水平切线，但这是飞椽的梢端界线，不能与摔网里口控制弧混为一条线。令 `dx=B_x-A_x`、`dy=B_y-A_y`，代码构造：

```text
R_end = (dx²+dy²)/(2dy)
θ_end = atan2(dx, R_end-dy)
x(θ) = A_x + R_end sin θ
y(θ) = A_y + R_end (1-cos θ)
θ ∈ [0, θ_end]
```

曲线以257个点采样并建立累计折线弧长，供交点与曲线分位查询。[飞椽外端曲线](../engine/stage04_core.py#L136)；[端点和弧长参数](../engine/stage04_core.py#L173)

立脚椽射线沿对应摔网椽中心方向；分别与共同的内边界、里口外边和梢端曲线求交，记为 `I`、`S`、`E`，要求 `q_I<q_S<q_E`。宽向单位向量为 `W=(-U_y,U_x)`，其中 `U` 是该根纵向单位方向。每根的根部法向厚度从梢厚向嫩戗端控制厚度平滑过渡：

```text
h_root(i) = h_tip + (0.65 H_young,root - h_tip) smooth((i-1)/(N-1))
smooth(x) = clamp(x,0,1)² [3-2 clamp(x,0,1)]
```

这里的厚度目标是截面控制量；不是“支点加高20 mm”或固定尾长比。[交点及厚度控制](../engine/stage04_core.py#L290)；[smoothstep](../engine/stage02_core.py#L45)

## 5. 共同虚拟母板、飞椽和同源承口

### 5.1 坐标带域和共用边界

对一根飞椽，中心线起点为 `S`，纵向单位向量为 `U`，宽向单位向量为 `W`。以里口外缘交点 `S` 为局部纵向零点：

```text
P(q,v) = S + q U + v W
-w_fly/2 ≤ v ≤ w_fly/2
```

所有飞椽先读取同一前缘路径、同一梢端路径及同一里口外边路径。对每个 `v`，其纵向控制轨与这三条公共路径相交，得到 `q_I(v)`、`q_E(v)`、`q_S(v)`。前缘点向内偏置 `flyer_edge_inboard_bias_mm`（默认0.05 mm）以留在下层望板覆盖内。单根横向轨站位须严格单调；内缘和梢缘上的成员顺序须一致，否则拒绝继续。[公共边界和各纤维交点](../engine/stage05_core.py#L234)；[横向单调性检查](../engine/stage05_core.py#L207)

一个飞椽的宽域记为 `W_i`，由其 A/B 两侧的纵向竖直分割面围成。母板 `M` 先由全翼有序控制轨建立，轨之间及椽间空档按相邻控制轨线性插值；最后才以 `F_i=M∩W_i` 得到各根实体。该顺序让飞椽边缘和相邻空档来自同一控制场，避免先独立造椽再补带隙。[母板构造与顺序守卫](../engine/stage05_core.py#L275)

### 5.2 顶面直母线与共同厚度场

对立脚飞椽，每个横向控制轨的梢端顶高程按共同梢端曲线过渡：

```text
z_E,top(v) = fly_top_at(E(v), f(v), γ)
fly_top_at = z_A,top + [z_B,top-z_A,top] f^γ
```

`f(v)` 是交点在已采样外端曲线上的弧长分位；`γ` 是当前过渡幂参数。正身飞椽沿用 stage04 梢端底面和厚度直接确定 `E_top=E_bottom+T_Z(q_E)`；立脚飞椽使用上式的曲线过渡。`I` 处下表面高程 `H_I(v)` 来自下层板三角网采样，上表面为 `H_I(v)+d_I(v)`。在 `I→E` 的同一条横向控制轨上，以配对端点直线插值：

```text
λ = (q-q_I(v))/(q_E(v)-q_I(v))
z_top(q,v) = (1-λ)[H_I(v)+d_I(v)] + λ z_E,top(v)
```

所以每条纵向母线由控制点连成直线；不同 `v` 的交点、端高和截面厚度可以不同。A/B 的高程差来自母面与侧分割面的相交，不再单独施加人为差值。[顶母线](../engine/stage05_core.py#L664)

法向厚度在给定纵向位置 `q` 上对同一根椽的横向纤维共用，根至梢线性变化：

```text
T_n(q) = T_root + (T_tip-T_root) (q-q_R0)/(q_tip-q_R0)
T_Z(q) = T_n(q) sqrt(1+g²)
z_bottom(q,v) = z_top(q,v)-T_Z(q)
```

`g` 是当前截面宽向斜率。乘 `sqrt(1+g²)` 把法向厚度换算到竖直厚度；所以 A/B 同一纵向位置的厚度相同，上下表面同步变化。R 到 I 也延用同一母面：根点 `R` 从共享上缘与下层板上表面的接触关系求得，底缘接到 `I` 的实测板面；R-I 与 I-E 分区但在 I 连续。[厚度场与母板说明](../engine/stage05_core.py#L612)；[根点求交](../engine/stage05_core.py#L708)

根点接触方程在每根横向纤维上为：

```text
gap(q,v) = z_top(q,v) - z_board,top(P(q,v))
求 q_R(v)，使 gap(q_R,v) ≈ 0.001 mm
```

这里的 `z_board,top` 来自下层望板的三角网采样器。求解器从 `I` 向内以5 mm步距找括区，在括区内二分到站位宽度不超过0.002 mm，最多搜索2200 mm。此条件是当前离散模型的闭合控制，不是实木留缝、承载或接触面的工法验收。[尾根搜索和二分](../engine/stage05_core.py#L708)

**边界说明：** stage04 的 `R0=-1.5 L` 是初始尾部候选和支承预检位置，也作为根厚到梢厚线性插值的参考站位。正式 stage05 的 `R` 由母线与板面求交；不强制最终尾长等于 `1.5L`，也没有额外抬高支点20 mm的目标。[初始候选及板面接触裁切](../engine/stage04_core.py#L439)

### 5.3 里口承口复用同一带域和底面

对同一根椽的同一个 `W_i`，承口刀具复用上述母板下表面 `z_bottom(q,v)`。刀具在纵向覆盖该带域与实际里口木实体的完整交集，并向上超过里口顶面；里口实体减去刀具体后形成承口。刀具不是用椽顶面封口，也不会只停在中心纤维的 `S` 站位。两根椽之间的里口齿保留，因为切削只发生于各自带域。[同源承口刀](../engine/stage05_core.py#L1541)

数学上，刀具的底边即共享母板下表面在 `W_i` 的限制；其横向边界由同一组 `v` 纤维控制，纵向端面封闭在实际木料包围域加安全余量处。代码把相邻纤维之间的底面做直纹面、顶面抬到安全高程，缝合成一个闭合刀体后再切里口。[承口裁切域及封闭](../engine/stage05_core.py#L1625)

## 6. 每翼连续上层卷戗板

卷戗板不是沿每根飞椽单独生成窄条。每翼由全部摔网飞椽的宽向控制轨、一个明确的正身边界飞椽，以及椽间线性过渡轨共同定义一张连续控制场；最后每翼只生成一片连续实体。里缘沿实际里口外缘 `S` 轨，外缘沿梢端 `E` 轨，两侧各按半档外推。[连续板支承和边界](../engine/stage05_core.py#L2522)

令 `u` 表示全翼宽向参数，`t∈[0,1]` 表示从里口外缘到梢端的站位。先在有序支承飞椽间线性插值，得到上层板底面控制点：

```text
P_lower(u,t) = Interp_width( flyer_top(q_S(v)+t[q_E(v)-q_S(v)], v) )
```

相邻椽的间隙用相邻边轨的线性插值补入。下表面相对椽顶上移 `upper_board_surface_overlap_mm`（默认0.2 mm）；该参数是竖向间隙，名称沿用历史字段，不表示实体体积重叠。下表面和上表面在共同张量参数网格上作三次 B 样条插值，默认共33个纵向站位；两张面边界之间用直纹侧壁封成每翼单一实体。[全翼站位及连续曲面](../engine/stage05_core.py#L2581)；[三次曲面构造与封壳](../engine/stage05_core.py#L2462)

厚度按底面的局部法向估算。若纵向、横向切向分别为 `P_t`、`P_u`，未归一化法向 `n=P_t×P_u`，其竖直分量比例为 `c_z=|n_z|/|n|`。设目标法向厚度 `T=board_upper_t`，则竖向偏移为：

```text
ΔZ = T / c_z
P_upper = P_lower + (0,0,ΔZ)
```

切向由离散站位差分估算；当 `c_z<0.5` 时拒绝换算，避免底面过陡导致厚度失稳。因此该偏移是采样曲面上的局部法向厚度近似；不等同于整张实物板的加工验证。[法向换算](../engine/stage05_core.py#L2094)；[上板厚度和连续片记录](../engine/stage05_core.py#L2635)

## 7. 立脚飞椽截面与排料近似

### 7.1 取哪一组几何

排料只收集一侧立脚飞椽，每根只取共同母板中心纤维 `v=0` 的纵向 `q-Z` 截面。它把该截面调整成可按直角侧立脚放置的梯形近似，并以 `w_fly` 作为板厚。排料不包含 A/B 两个斜侧面的精确展开，也不改写三维模型。[中心纤维取样和梯形构造](../generate.py#L225)

这一侧得到的模板组按建筑对称关系制作两套。样板编号对应不同的立脚飞椽中心截面，不等于左右翼分别重算出来的两种版型。

记中心纤维实际里口底点 `I_b=(q_I,H_I)`，梢部底/顶点 `E_b=(L,z_Eb)`、`E_t=(L,z_Et)`，里口顶点 `I_t=(q_I,H_I+d_I)`，尾根站位为 `q_R`。先按梢顶线从 `I_t` 外推到 `q_R` 得来源尾顶：

```text
m_t = (z_Et-z_It)/(L-q_I)
R_source = (q_R, z_It + m_t(q_R-q_I))
```

再求底边斜率 `m_b=(z_Eb-H_I)/(L-q_I)`。让新里口顶 `I_t'` 落在过 `E_t` 且斜率为 `m_b` 的直线上，然后以 `I_b—R_source` 和 `I_t'—E_t` 两直线的交点作为排料近似的 `R`：

```text
I_t' = (q_I, z_Et + m_b(q_I-L))
R = intersection(line(I_b,R_source), line(I_t',E_t))
```

排料梯形四角按 `A=R`、`B=I_b`、`C=E_b`、`D=E_t` 记。上述构造让侧立加工图使用共底线、同侧厚度约束的截面近似；被调整的 `R`、`I_t'` 与原中心纤维量之间的偏移会保存在 `adjustments` 诊断字段。[截面端点和校正量](../generate.py#L235)

### 7.2 局部坐标、靠紧排布和面积

在 `q-Z` 平面令底边方向 `u=(C-B)/|C-B|`，横向轴 `e_x=(u_z,-u_q)`。以 `A` 为局部原点，将任一点 `P` 变换为：

```text
X(P) = (P-A)·e_x
Y(P) = (P-A)·u
w_i = X(B) > 0
```

各片沿同一底线依次靠紧，累积边界 `x_0=0`、`x_i=Σ(j=1…i) w_j`。放置角点为：

```text
A_i=(x_(i-1),0)    B_i=(x_i,b_i)
C_i=(x_i,c_i)      D_i=(x_(i-1),d_i)
```

所以每根 AD、BC 是竖直长边，A 角落在公共底线上。板宽为 `x_N`；板高取所有 B/C/D 的最大纵坐标；每根梯形面积由鞋带公式求得：

```text
Area = 1/2 |Σ_j (X_j Y_(j+1)-Y_j X_(j+1))|
```

几何字段里的分椽档 `B` 与排料宽度 `w_i` 不同；这里的宽度来自每根实际中心截面变换，不从分椽档直接赋值。[坐标变换和靠紧规则](../generate.py#L364)

### 7.3 三条独立自然三次样条

以所有实际排料角点建立三组节点：`b(x_i)=Y(B_i)`、`c(x_i)=Y(C_i)`、`d(x_(i-1))=Y(D_i)`。对每个节点区间 `[x_i,x_(i+1)]`，自然三次段写作：

```text
S_i(x)=a_i Δx³+b_i Δx²+c_i Δx+d_i,   Δx=x-x_i
```

它精确通过输入节点；相邻段的一阶、二阶导数连续，首尾端二阶导数为零。`b`、`c`、`d` 分别独立求解。排料切割外框仍由每片实际梯形的四个角用直线连接；样条用于观察连续包络与定位，不替代这些角点轮廓。[自然三次拟合](../generate.py#L299)；[三组节点及实际轮廓](../generate.py#L397)

展示的 Bézier 控制点是对既有分段三次多项式的精确参数换算，不会重新拟合或移动节点。若 `h=x_1-x_0`，段系数为 `(a,b,c,d)`，左右端斜率为：

```text
s_0 = c
s_1 = 3a h² + 2b h + c
P_0 = (x_0,y_0)
P_1 = (x_0+h/3, y_0+h s_0/3)
P_2 = (x_1-h/3, y_1-h s_1/3)
P_3 = (x_1,y_1)
```

`P_0/P_3` 在曲线上；通常 `P_1/P_2` 不在曲线上，只控制曲线形状。[Bézier 控制点换算](../layout.js#L5)；[页面显示与坐标表](../layout.js#L68)

### 7.4 `c` 与 `d` 的平移误差

另计算一个诊断近似 `ĉ(x)=d(x-Δx)+Δy`，尝试以平移后的 `d` 近似 `c`。对每个 C 节点横坐标 `x_j`：

```text
r_j(Δx) = c_j - d(x_j-Δx)
Δy = (max_j r_j + min_j r_j)/2
e_j = Δy-r_j
```

固定 `Δx` 时，`Δy` 把上下极值残差居中，因而最大绝对误差是两端残差跨度的一半。程序在 `[-板宽,2·板宽]` 内先取1201点网格，细化局部极小并检查样条折点差候选；记录最大绝对误差和 RMS。这个平移只用于比较曲线形状，不改变 `c`、`d`、排料外框或飞椽三维几何。[平移搜索与目标](../generate.py#L321)

## 8. 连续公式与数值实现的边界

| 部位 | 几何定义 | 当前数值实现 | 应如何读结果 |
| --- | --- | --- | --- |
| 建筑角及镜像 | 半角三角函数、平面刚体反射 | 基于双精度浮点和 CAD 布尔/曲面 | 尺寸不因角度整体放缩 |
| 摔网控制弧 | 端点与切线唯一确定的圆弧 | 129站折线用于分椽和面场 | 矢高是推导值，55 mm仅参考 |
| 飞椽梢端弧 | 端点和正身端切线确定的圆弧 | 257站折线和累计弧长 | 站位、交点受折线离散影响 |
| 嫩戗车背 | 弦长/矢高圆弧 | 33个弦向站位 | 只弯车背，不弯主体中心线 |
| 下层板面采样 | 正身共面、摔网扇区控制面 | 三角网供支承查询；固定样点估算面偏差 | 固定网格结果不是全域误差上界 |
| 母板横向 | 相邻有序控制轨之间的分片直纹插值 | 默认17个宽向纤维站位，带内分成16格并融合 | 纤维/网格采样不证明加工连续性 |
| 后尾根点 | 共享顶母线与板顶高程闭合 | 5 mm 搜索括区，二分至站位宽度≤0.002 mm；gap目标0.001 mm | 是当前三角网采样下的数值求交 |
| 里口承口 | 共享带域内母板底面与里口求差 | 封闭直纹刀体，缝合容差1e-6 mm | 几何同源，不是实物装配验收 |
| 上层卷戗板 | 一翼一张连续上下曲面 | 33纵向站位，张量三次 B 样条，法向由离散差分估算 | 厚度是采样局部法向换算 |
| 排料样条 | 每组三次自然插值 | 通过角点节点；端段可延长 | 仅展示/定位；角点折线仍是排料边界 |
| `c` 对 `d` 平移 | 最小化 C 节点处竖向最大误差 | 有界网格搜索、局部细化及折点候选 | 诊断量，不回馈3D模型 |

实现中的几何容差、三角网弦高和采样点数解决的是数值构造问题。样点之间仍可能有偏差；BRep/网格生成成功、曲面相接或厚度采样为正，都不能单独推导历史工法、实体可加工性、材料强度或承载安全结论。
